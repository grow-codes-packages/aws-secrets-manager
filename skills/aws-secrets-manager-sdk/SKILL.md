# AWS Secrets Manager SDK (Grow Codes)

One API for AWS Secrets Manager in five languages (categories: secrets). Pick the package for the
project's language, configure it from the environment, and handle errors by their canonical code.

## 1. Add the package

| Language | Command | Import |
| - | - | - |
| TypeScript | `npm install @grow-codes/aws-secrets-manager` | `import { AwsSecretsManagerClient } from "@grow-codes/aws-secrets-manager"` |
| Rust | `cargo add grow-aws-secrets-manager` (add `tokio` with `macros,rt-multi-thread`) | `use grow_aws_secrets_manager::AwsSecretsManagerClient;` |
| Go | `go get github.com/grow-codes-packages/aws-secrets-manager/go` | `awssecretsmanager "github.com/grow-codes-packages/aws-secrets-manager/go"` |
| Python | `pip install grow-aws-secrets-manager` (or `uv add grow-aws-secrets-manager`) | `from grow_aws_secrets_manager import AwsSecretsManagerClient` |
| Java | Maven `codes.grow.packages:aws-secrets-manager` (Gradle `implementation("codes.grow.packages:aws-secrets-manager:<version>")`) | `import codes.grow.packages.awssecretsmanager.AwsSecretsManagerClient;` |

Check the latest version in the README badges before pinning one.

## 2. Configure

Prefer environment configuration so no credential is written into code:

```sh
export GROW_AWS_SECRETS_MANAGER_URL=https://aws-secrets-manager.example.internal
export GROW_AWS_SECRETS_MANAGER_TOKEN=...            # from your secret store, never committed
```

Precedence: explicit config value > `GROW_AWS_SECRETS_MANAGER_*` > vendor variables (standard AWS chain (`AWS_REGION`, `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`, `AWS_SESSION_TOKEN`, `AWS_PROFILE`, `AWS_ENDPOINT_URL_SECRETS_MANAGER`), `GROW_AWS_SECRETS_MANAGER_*`) > default.
Other variables: `…_CONNECT_TIMEOUT`, `…_REQUEST_TIMEOUT`, `…_TOTAL_TIMEOUT` (`10s`, `1500`),
`…_MAX_RETRIES`, `…_CA_CERT`, `…_CLIENT_CERT`, `…_CLIENT_KEY`, `…_PROXY`. Environment proxies
(`HTTPS_PROXY`) are ignored unless `proxy` is set.

## 3. Use

Create one client per process and close it on shutdown (TypeScript `await client.close()`, Rust
`client.close().await`, Go `defer client.Close()`, Python `with …`/`close()`, Java
try-with-resources).

- `health()` never throws for an unhealthy service; check `healthy`.
- `ping()` verifies credentials (`AUTHENTICATION` error when they are wrong).
- All I/O is retried with jitter on 429/502/503/504 and connection errors; only idempotent calls
  are retried on 500.
- Errors carry `code` (`CONFIG`, `AUTHENTICATION`, `PERMISSION_DENIED`, `NOT_FOUND`, `CONFLICT`,
  `RATE_LIMITED`, `VALIDATION`, `UNAVAILABLE`, `TIMEOUT`, `UNSUPPORTED`, `CANCELLED`), `retryable`,
  `httpStatus` and `requestId`. Branch on the code, not on the message text. Go:
  `errors.Is(err, awssecretsmanager.ErrNotFound)`.

### Secrets

Read with `get`/`getString`/`getJson`/`require` (missing → `null`/`None`/`nil`, `require` →
`NOT_FOUND`), write with `set`, list with `list`, load into the environment with `loadEnv`, watch
with `watch`. Wrap the provider in `SecretCache` for hot paths. Values are `SecretValue` objects:
call `reveal()` only where the plain value is needed and never log it.

## 4. Test code that uses the SDK

Use the in-memory fakes from the testing module instead of a real AWS Secrets Manager in unit tests:
TypeScript `@grow-codes/aws-secrets-manager/testing`, Rust feature `testing`, Go package `testkit`, Python
`grow_aws_secrets_manager.testing`, Java `codes.grow.packages.awssecretsmanager.testing`.

## 5. Work on this repository

Read `AGENTS.md` first. Short version: the five languages keep the same API; files with the
`Generated by sdk-kit` header are changed in sdk-kit, not here; `make lint coverage` must pass
(≥ 90 % lines and branches); `make test-docker LANGS="<lang>"` runs the integration suite against
`motoserver/moto:5.2.4`.
